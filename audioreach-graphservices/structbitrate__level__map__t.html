Detailed Description

@h2xmlp_parameter {"PARAM_ID_LDAC_BIT_RATE_LEVEL_MAP", PARAM_ID_LDAC_BIT_RATE_LEVEL_MAP} @h2xmlp_description {- Configures the table which maps each bitrate level received to the actual bitrate value
-> Quality levels are always in ascending order of bit rate

  • (even if we add a new level at the bottom in the future)
  • i.e. a lower quality level always refers to a lower bit rate
    -> For a given bit rate level, the encoder will never encode at a
  • bit rate higher than that defined by the corresponding mapping
    -> The mapping table can be sent multiple times on the fly and each time,
  • the new table received will be cached and used to set the bitrate for the next frame.} @h2xmlp_toolPolicy {Calibration}
