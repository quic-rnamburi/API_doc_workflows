◆ EVENT_ID_VOCODER_OPERATING_MODE

#define EVENT_ID_VOCODER_OPERATING_MODE   0x08001197

Event ID that is raised by the vocoder when client registers for operating mode updates with the vocoder.

Payload of the event contains the operating mode details. We have 4 operating modes - one for each of 8k/16k/32k/48k bandwidths

◆ PARAM_ID_VOCODER_RESET

#define PARAM_ID_VOCODER_RESET   0x08001128

Parameter to reset voice encoder/decoder.

This param id can be used reset vocoder whenever client sends homing sequence to network. Since these homing sequence reset far end decoder, client can use this param id to reset near end encoder so that both encoder and decoder are in sync. This param doesn't have any payload associated with it. Once module receives this param, it is expected to RESET itself
