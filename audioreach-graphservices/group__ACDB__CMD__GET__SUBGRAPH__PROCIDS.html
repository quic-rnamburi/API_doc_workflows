#define ACDB_CMD_GET_SUBGRAPH_PROCIDS   ACDB_CMD_ID(17)

Queries all supported proc ids for a given list of subgraphs.

Parameters
[in]cmd_idCommand ID is ACDB_CMD_GET_SUBGRAPH_PROCIDS.
[in]cmdThis is a pointer to AcdbCmdGetSubgraphProcIdsReq.
[in]cmd_sizeThis is the size of AcdbCmdGetSubgraphProcIdsReq.
[out]rspThis is a pointer to AcdbCmdGetSubgraphProcIdsRsp.
[in]rsp_sizeThis is the size of AcdbCmdGetSubgraphProcIdsRsp.
Returns
  • AR_EOK – Command executed successfully.
  • AR_EBADPARAM – Invalid input parameters were provided.
  • AR_EFAILED – Command execution failed.
  • AR_ENOTEXIST – No Subgraph ID or Proc ID is found.
