Detailed Description

@h2xmlp_parameter {"PARAM_ID_PCM_OUTPUT_FORMAT_CFG", PARAM_ID_PCM_OUTPUT_FORMAT_CFG} @h2xmlp_description {Param-ID to configure the PCM output format of PCM encoder, decoder or converter.

Example scenarios that need this parameter are:

– decoder -> pcm converter: This param must be set on both decoder and converter. The converter will act as back-up for the decoder. E.g. for 24 bit output, both decoder and converter are configured to have 24 bit output. In case the decoder can output at 24 bit, then converter is pass-through. Otherwise, converter will do 16 to 24 bit conversion.

– pcm converter -> encoder: This param must be set on converter only.

– pcm converter use cases in PP/EP containers (E.g. pull mode/push mode).
