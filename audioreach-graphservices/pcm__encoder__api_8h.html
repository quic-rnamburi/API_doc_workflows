◆ PARAM_ID_PCM_ENCODER_FRAME_SIZE

#define PARAM_ID_PCM_ENCODER_FRAME_SIZE   0x0800136B

ID of the parameter used to set frame size of the pcm encoder In general,the PCM encoder frame size is determined by the perf_mode of the container.For Low latency it is 1 ms and for low Power it is 5 ms.

This PID can be used, if the client has the requirement to specify any fixed frame-size for PCM encoder.
