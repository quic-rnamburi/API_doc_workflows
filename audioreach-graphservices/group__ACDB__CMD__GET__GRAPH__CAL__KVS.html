◆ ACDB_CMD_GET_GRAPH_CAL_KVS

#define ACDB_CMD_GET_GRAPH_CAL_KVS   ACDB_CMD_ID(20)

Queries for all SPF module calibration key vectors under a given graph key vector.

Example: If the ACDB file contains the usecase GKV: <Stream, HandsetMic><DeviceRx, FluenceSM><Instance, 1>

and this usecase contains the calibration key Tables:

Volume Step Sample Rate
1 8k
2 8k

Volume Step

1 2

The resulting key vector list will contain: CKV [] (default CKV aka zero CKV) CKV [<Volume Step, 1>] CKV [<Volume Step, 2>] CKV [<Volume Step, 1><Sample Rate, 8k>] CKV [<Volume Step, 2><Sample Rate, 8k>]

Parameters
[in]cmd_idCommand ID is ACDB_CMD_GET_GRAPH_CAL_KVS.
[in]cmdThis is a pointer to AcdbGraphKeyVector.
[in]cmd_sizeThis is the size of AcdbGraphKeyVector.
[out]rspThis is a pointer to AcdbKeyVectorList.
[in]rsp_sizeThis is the size of AcdbKeyVectorList.
Returns
  • AR_EOK – Command executed successfully.
  • AR_EBADPARAM – Invalid input parameters were provided.
  • AR_EFAILED – Command execution failed.
  • AR_ENOTEXIST – The graph key vector does not exist or no data was found.
