#define DATA_CMD_RD_SH_MEM_EP_DATA_BUFFER   0x04001003

@h2xml_title1 {APIs of Read Shared Memory End Point Module} @h2xml_title_agile_rev {APIs of Read Shared Memory End Point Module} @h2xml_title_date {August 13, 2018}

@h2xmlx_xmlNumberFormat {int} Data command to send an empty buffer to the shared memory end point module. RD_SHARED_MEM_EP writes to this buffer & client reads.

This command can be used to read PCM, raw compressed as well as packetized streams.

Once buffer is filled, DATA_CMD_RSP_RD_SH_MEM_EP_DATA_BUFFER_DONE event is raised.
