Release HW resource configuration.

Clients provide the configuration that needs to be sent to SPF PRM module

Parameters
[in]payloadPointer to HW resource configuration payload should be in the form {MIID, PID, size, error_code} followed by variable payload. Client is expected to send only one PID at a time using this API.
[in]payload_sizeSize of the HW resource configuration
[in,out]buffOPTIONAL buffer to receive the response payload from Spf. Will be filled if present.
[in,out]buff_sizeOPTIONAL size of memory allocated for buff. If buff is written to, contains the number of bytes written.
Returns
AR_EOK on success, error code otherwise
