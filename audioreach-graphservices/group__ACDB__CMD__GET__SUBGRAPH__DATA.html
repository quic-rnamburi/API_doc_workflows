#define ACDB_CMD_GET_SUBGRAPH_DATA   ACDB_CMD_ID(2)

Queries ACDB SW for container and module connection data (connections between modules within a subgraph) for a specific subgraph.

Parameters
[in]cmd_idCommand ID is ACDB_CMD_GET_SUBGRAPH_DATA.
[in]cmdPointer to AcdbSgIdGraphKeyVector.
[in]cmd_sizeSize of AcdbSgIdGraphKeyVector.
[out]rspThis is a pointer to AcdbGetSubgraphDataRsp. AcdbGetSubgraphDataRsp Description.
[in]rsp_sizeThis must equal the size of AcdbBlob.
Returns
  • AR_EOK – Command executed successfully.
  • AR_EBADPARAM – Invalid input parameters were provided.
  • AR_EFAILED – Command execution failed.
