#define ACDB_CMD_GET_AMDB_REGISTRATION_DATA   ACDB_CMD_ID(15)

Queries AMDB data for one Processor ID to register all dynamic custom modules.

Parameters
[in]cmd_idCommand ID is ACDB_CMD_GET_AMDB_REGISTRATION_DATA.
[in]cmdThis is a pointer to AcdbAmdbProcID.
[in]cmd_sizeThis is the size of AcdbAmdbProcID.
[out]rspThis is a pointer to AcdbBlob.
[in]rsp_sizeThis is the size of AcdbBlob.
Returns
  • AR_EOK – Command executed successfully.
  • AR_EBADPARAM – Invalid input parameters were provided.
  • AR_EFAILED – Command execution failed.
  • AR_ENOTEXIST – No Proc ID is found.
