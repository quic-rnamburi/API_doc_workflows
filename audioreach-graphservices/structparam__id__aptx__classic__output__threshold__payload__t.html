Detailed Description

@h2xmlp_parameter {"PARAM_ID_APTX_CLASSIC_SET_OUTPUT_THRESHOLD", PARAM_ID_APTX_CLASSIC_SET_OUTPUT_THRESHOLD} @h2xmlp_description {- Configures the output threshold of aptX Classic Encoder.


  • Permissible values are in the range 64 to 1500 bytes..
  • .. and must be divisible by 4, since 4 is the smallest possible output 'packet' from Classic Encoder.
    -> Values outside the above range, or not divisible by 4, are rejected with EBADPARAM return code.
    -> Since aptX compression ratio is fixed at 4:1, the input threshold is also configured from the output threshold.} @h2xmlp_toolPolicy {Calibration}
