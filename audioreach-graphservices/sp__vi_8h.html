  • PARAM_ID_SP_VI_OP_MODE_CFG

  • PARAM_ID_SP_VI_CFSMOOTHING_CFG_PARAM

It also supports the following events:

  • EVENT_ID_SPv5_SPEAKER_DIAGNOSTICS The payload of this event includes num channels followed by status of DC presence on each channel
  • EVENT_ID_VI_CALIBRATION It populates and returns the payload corresponding to 'PARAM_ID_SP_TH_VI_CALIB_RES_CFG' param

  • EVENT_ID_TH_VI_V_VALI_PARAMS It populates and returns the payload corresponding to 'PARAM_ID_SP_TH_VI_V_VALI_PARAMS' param

    All parameter IDs are device independent.
    Supported Input Media Format:

Data Format : FIXED_POINT

  • fmt_id : Don't care
  • Sample Rates : 48000, 8000
  • Number of channels : 1 to 8
  • Channel type : 1 to 63
  • Bits per sample : 16 , 32
  • Q format : 15 for bps = 16 and 27 for bps = 32
  • Interleaving : de-interleaved unpacked

  • Signed/unsigned : Signed }
