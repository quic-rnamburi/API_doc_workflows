uint32_t module_cmn_md_encoder_per_frame_info_t::flags

Frame flags.

@values{for bit 31}

  • 1 – Timestamp is valid
  • 0 – Timestamp is not valid
  • To set this bit, use #RD_SH_MEM_EP_BIT_MASK_TIMESTAMP_VALID_FLAG and RD_SH_MEM_EP_SHIFT_TIMESTAMP_VALID_FLAG

All other bits are reserved; the spf sets them to 0.
