◆ ACDB_CMD_GET_GRAPH_ALIAS

#define ACDB_CMD_GET_GRAPH_ALIAS   ACDB_CMD_ID(33)

Retrieves an alias of the graph key vector.

The alias includes the the usecase ID followed by a human readable graph key vector with names for keys and values. The string length is limited to 255 bytes.

Example Usecase ID with GKV: "100 [Device: Speaker] [Instance: 1]" Just Usecase ID: "100"

Parameters
[in]cmd_idCommand ID is ACDB_CMD_GET_GRAPH_ALIAS.
[in]cmdThere is a pointer to AcdbGraphKeyVector
[in]cmd_sizeThere is the size of AcdbGraphKeyVector
[out]rspThis is a pointer to AcdbString
[in]rsp_sizeThis is the size of AcdbString
Returns
  • AR_EOK – Command executed successfully.
  • AR_EBADPARAM – Invalid input parameters were provided.
  • AR_EFAILED – Command execution failed.
  • AR_ENOTEXIST – Graph Key Vector not found
  • AR_ENOMEMORY – Not enough memory to write the alias string
