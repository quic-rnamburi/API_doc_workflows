◆ PARAM_ID_FLUENCE_CMN_GLOBAL_EFFECT

#define PARAM_ID_FLUENCE_CMN_GLOBAL_EFFECT   0x080010BB

Param ID to support dynamic enablement/disablement of Audio effects.

This PID will be common for all audio effects and will be shared accross multiple module IDs. HLOS will use regular set/get param interface to set/get effects to/from DSP. This PID will not be visible in ARCT. Each module will generally use 0th bit to set effect. If a module supports more than one effect than subsequent LSB bits can be used.

payload size – 4 bytes
