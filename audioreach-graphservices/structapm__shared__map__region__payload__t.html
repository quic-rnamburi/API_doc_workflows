uint32_t apm_shared_map_region_payload_t::mem_size_bytes

Number of bytes in the region.

@values Multiples of 4 KB

The APM always maps the regions as virtual contiguous memory, but the memory size must be in multiples of 4 KB to avoid gaps in the virtually contiguous mapped memory.

uint32_t apm_shared_map_region_payload_t::shm_addr_msw

Upper 32 bits of the shared memory address of the memory region to map.

This word must be contiguous memory, and it must be 4 KB aligned.

@valuesbul
