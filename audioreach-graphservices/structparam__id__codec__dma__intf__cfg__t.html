uint32_t param_id_codec_dma_intf_cfg_t::active_channels_mask

Active channels mask to denote the bit mask for active channels.

Bits 0 to 15 denote channels 0 to 15. A set bit in the mask denotes the channel is active while a 0 denotes a channel is inactive. Mask should match the channel indices being set from codec side. @h2xmle_description {Active channels mask to denote the bit mask for active channels. Bits 0 to 15 denote channels 0 to 15.
