#define ACDB_CMD_GET_TAGS_FROM_GKV   ACDB_CMD_ID(19)

Query ACDB SW for all the tags(and their associated modules) that are used within a usecase given the graph key vector.

Parameters
[in]cmd_idCommand ID is ACDB_CMD_GET_TAGS_FROM_GKV.
[in]cmdThis is a pointer to AcdbCmdGetTagsFromGkvReq.
[in]cmd_sizeThis is the size of AcdbCmdGetTagsFromGkvReq.
[out]rspThis is a pointer to AcdbCmdGetTagsFromGkvRsp.
[in]rsp_sizeThis is the size of AcdbCmdGetTagsFromGkvRsp.
Returns
  • AR_EOK – Command executed successfully.
  • AR_EBADPARAM – Invalid input parameters were provided.
  • AR_EFAILED – Command execution failed.
  • AR_ENOTEXIST - The grah key vector does not exist or there are no tags to return.
