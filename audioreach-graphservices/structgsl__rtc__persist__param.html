uint8_t* gsl_rtc_persist_param::sg_cal_data

Pointer to persist cal data.

The data in this buffer can contain one or more parameters in the form - {MIID, PID, Size, ErrorCode, VariablePayload}

In the case where this structure is passed in as part of set this pointer will be set by the caller. In the case of get it will be set by gsl.

Setting the pointer to NULL results in GSL to query the data from ACDB using the CKV below
