uint32_t module_cmn_md_buffer_end_t::flags

< Specifies the higher 32 bits of the 64-bit unique buffer index

Field to specify any related information to from/to the client.

BIT_0 : specifies if any frame in the buffer has error 0 : no error 1 : at least one frame in the buffer has error BIT_1 : specifies if error recovery was done for any frame in the buffer 0 : no error recovery 1 : at least one frame in the buffer was recovered

Other bit field values are reserved for future use and must be set to 0
