Detailed Description

Configures whether to act as a threshold module.

The threshold can be configured to be hard or soft. A hard threshold means that the module will raise a port threshold event, and will error out from the process() call if there is not enough data in the input or space in the output to process the entire threshold. A soft threshold means that the module will not raise a port threshold event. During process(), the module will process at MOST the threshold amount of data. If less data than the threshold is provided, all data will be processed.
