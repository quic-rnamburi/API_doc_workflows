◆ ACDB_CMD_GET_PROC_SUBGRAPH_CAL_DATA_PERSIST

#define ACDB_CMD_GET_PROC_SUBGRAPH_CAL_DATA_PERSIST   ACDB_CMD_ID(29)

Retrieves subgraph calibration data for persistent parameters under a given processor.

The output blob is in the format of:

+-------------------------------------------------------—+ | Subgraph #1 | +-------------------------------------------------------—+ | Subgraph ID | Persist Data Size | +----------—+-------—+---—+---------—+----------—+ | Instance ID | Param ID | Size | Error Code | Data[Size] | +----------—+-------—+---—+---------—+----------—+ ... +----------—+-------—+---—+---------—+----------—+ | Instance ID | Param ID | Size | Error Code | Data[Size] | +----------—+-------—+---—+---------—+----------—+ ... +-------------------------------------------------------—+ | Subgraph #N | +-------------------------------------------------------—+ | Subgraph ID | Persist Data Size | +----------—+-------—+---—+---------—+----------—+ | Instance ID | Param ID | Size | Error Code | Data[Size] | +----------—+-------—+---—+---------—+----------—+ ... +----------—+-------—+---—+---------—+----------—+ | Instance ID | Param ID | Size | Error Code | Data[Size] | +----------—+-------—+---—+---------—+----------—+

Parameters
[in]cmd_idCommand ID is ACDB_CMD_GET_PROC_SUBGRAPH_CAL_DATA_PERSIST
[in]cmdThis is a pointer to AcdbProcSubgraphPersistCalReq
[in]cmd_sizeThis is the size of AcdbProcSubgraphPersistCalReq
[out]rspThis is a pointer to AcdbSgIdsPersistCalData
[in]rsp_sizeThis is the size of AcdbSgIdsPersistCalData
Returns
  • AR_EOK – Command executed successfully.
  • AR_EBADPARAM – Invalid input parameters were provided.
  • AR_EFAILED – Command execution failed.
See also
acdb_ioctl ACDB_CMD_GET_SUBGRAPH_CALIBRATION_DATA_PERSIST ACDB_CMD_GET_HW_ACCEL_SUBGRAPH_INFO Applies the memory type to the Proc ID. The upper two bits of the Proc ID represent memory types that AML will use to filter calibration. The memory types are: System Heap(0x0), Physically Contiguous Memory (0x01)
