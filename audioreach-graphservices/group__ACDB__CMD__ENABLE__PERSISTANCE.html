#define ACDB_CMD_ENABLE_PERSISTANCE   ACDB_CMD_ID(13)

Enable ACDB calibration data persistance.

Calibration data set to ACDB will be persisted to a *.acdbdelta file

Parameters
[in]cmd_idCommand ID is ACDB_CMD_ENABLE_PERSISTANCE.
[in]cmdThere is no input structure; set this to NULL.
[in]cmd_sizeThere is no input structure; set this to 0.
[out]rspThere is no output structure; set this to NULL.
[in]rsp_sizeThere is no output structure; set this to 0.
Returns
  • AR_EOK – Command executed successfully.
  • AR_EBADPARAM – Invalid input parameters were provided.
  • AR_EFAILED – Command execution failed.
