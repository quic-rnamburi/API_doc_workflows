◆ flags

uint32_t ar_shmem_info_t::flags

in, Bit field for flags.

@values{for bit 0}

  • 1 – hardware accelerator enabled, use AR_SHMEM_HW_ACCELERATOR_ENABLED
  • 0 – hardware accelerator disabled, use AR_SHMEM_HW_ACCELERATOR_DISABLED
  • To set this bit, use AR_SHMEM_BIT_MASK_HW_ACCELERATOR_FLAG and AR_SHMEM_SHIFT_HW_ACCELERATOR_FLAG All other bits are reserved; must be set to 0.
