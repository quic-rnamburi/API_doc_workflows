Detailed Description

@h2xmlp_parameter {"PARAM_ID_AAC_SBR_SIGNALLING", PARAM_ID_AAC_SBR_SIGNALLING} @h2xmlp_description {Parameter for configuring AAC decoder SBR signaling.

This parameter applies only to AAC bit stream decoding. The command is sent after opening a write or read/write stream and before actual decoding begins. The parameter is used to select the stereo mix coefficients between the ISO/IEC and ARIB standards. Do not send this command during decoding. Such a change can cause glitches in the stereo output.} @h2xmlp_toolPolicy {Calibration}
