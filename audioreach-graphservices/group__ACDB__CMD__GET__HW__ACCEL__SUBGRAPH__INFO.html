◆ ACDB_CMD_GET_HW_ACCEL_SUBGRAPH_INFO

#define ACDB_CMD_GET_HW_ACCEL_SUBGRAPH_INFO   ACDB_CMD_ID(28)

Sets tag data to the AML heap and persist to delta file.

The input blob is in the format of: +----------—+-------—+---—+---------—+----------—+ | Instance ID | Param ID | Size | Error Code | Data[Size] | +----------—+-------—+---—+---------—+----------—+ ... +----------—+-------—+---—+---------—+----------—+ | Instance ID | Param ID | Size | Error Code | Data[Size] | +----------—+-------—+---—+---------—+----------—+

Parameters
[in]cmd_idCommand ID is ACDB_CMD_GET_HW_ACCEL_SUBGRAPH_INFO.
[in]cmdThis is a pointer to AcdbGetTagDataReq.
[in]cmd_sizeThis is the size of AcdbGetTagDataReq.
[out]rspThere is no output structure; set this to NULL.
[in]rsp_sizeThere is no output structure; set this to 0.
Returns
  • AR_EOK – Command executed successfully.
  • AR_EBADPARAM – Invalid input parameters were provided.
  • AR_EFAILED – Command execution failed.
