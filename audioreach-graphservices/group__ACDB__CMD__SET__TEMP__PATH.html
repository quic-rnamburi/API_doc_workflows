#define ACDB_CMD_SET_TEMP_PATH   ACDB_CMD_ID(27)

Updates the read/write temporary path that AML uses for the reinit/delta persistence functionality.

This function also updates the delta file manager to use the read/write delta file if it exists in the read/write path provided. The delta data from the read/write path will be merged on top of the delta data that is provided during acdb_init(...).

Parameters
[in]cmd_idCommand ID is ACDB_CMD_SET_TEMP_PATH.
[in]cmdThis is a pointer to AcdbSetTempPathReq.
[in]cmd_sizeThis is the size of AcdbSetTempPathReq.
[out]rspThere is no output structure; set this to NULL.
[in]rsp_sizeThere is no output structure; set this to 0.
Returns
  • AR_EOK – Command executed successfully.
  • AR_EBADPARAM – Invalid input parameters were provided.
  • AR_EFAILED – Command execution failed.
