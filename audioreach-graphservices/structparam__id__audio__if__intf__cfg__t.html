◆ active_lane_mask

uint32_t param_id_audio_if_intf_cfg_t::active_lane_mask

Position of the active audio_if lanes: 1 to ((2^N)-1), where N is the number of physical lanes supported by the hardware interface.

Bits 0 to N-1 correspond to lanes 0 to N-1. When a bit is set, the corresponding lane is active.

The number of active lanes can be inferred from the number of bits set in the mask.

◆ active_slot_mask

uint32_t param_id_audio_if_intf_cfg_t::active_slot_mask

Specifies the position of the active slot.

@values 1 through (2^32)-1 (Default = 1)

Bits 0 to 31 correspond to slots 0 to 31. When a bit is set, the corresponding slot is active. The number of active slots can be inferred from the number of bits set in the mask.

32 individual bits can be enabled.
