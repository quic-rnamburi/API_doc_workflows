◆ ACDB_CMD_GET_MODULE_TAG_DATA

#define ACDB_CMD_GET_MODULE_TAG_DATA   ACDB_CMD_ID(9)

Query for all necessary data for the given SGID, module_tag, and keys.

Clients should provide “Don’t care” value for those tag indices which are not used in a tag_key_vec. For a given tag, all its indices should be provided with a value.

Parameters
[in]cmd_idCommand ID is ACDB_CMD_GET_MODULE_TAG_DATA.
[in]cmdThis is a pointer to AcdbGetModuleTagCmd.
[in]cmd_sizeThis is the size of AcdbGetModuleTagCmd.
[out]rspThis is a pointer to AcdbBlob.
[in]rsp_sizeThis is the size of AcdbBlob.
Returns
  • AR_EOK – Command executed successfully.
  • AR_EBADPARAM – Invalid input parameters were provided.
  • AR_EFAILED – Command execution failed.
