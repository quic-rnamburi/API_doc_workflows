Detailed Description

Cmd payload for GSL_CMD_GET_WRITE_BUFF_INFO and GSL_CMD_GET_READ_BUFF_INFO.

GSL writes to the payload created by the caller. Caller is responsible to provide the appropriate amount of memory to hold addresses for all buffers.
