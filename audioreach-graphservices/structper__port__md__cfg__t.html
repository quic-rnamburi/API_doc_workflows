Detailed Description

@h2xmlm_module {"MODULE_ID_SPLITTER", MODULE_ID_SPLITTER} @h2xmlm_displayName {"Splitter"} @h2xmlm_description {ID of the SPLITTER module.

This module is used to split the streams on the input to all the output ports.

Supported Input Media Format:

  • Data Format : FIXED_POINT
  • fmt_id : Don't care
  • Sample Rates : Any (>0)
  • Number of channels : 1 to 32
  • Channel type : 1 to 63
  • Bits per sample : 16, 24, 32
  • Q format : 15, 27, 31
  • Interleaving : Any
  • Signed/unsigned : Any
