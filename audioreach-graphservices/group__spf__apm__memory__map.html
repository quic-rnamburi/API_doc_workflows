#define APM_CMD_GLOBAL_SHARED_MEM_MAP_REGIONS   0x01001059

Commands the APM to map multiple shared memory regions from a memory pool and associate it with the specified shmem_id.

SPF-client is expected to map these memory regions with other SPF instances if needed.

◆ APM_CMD_GLOBAL_SHARED_MEM_UNMAP_REGIONS

#define APM_CMD_GLOBAL_SHARED_MEM_UNMAP_REGIONS   0x0100105A

Commands the APM to unmap global shared memory regions that were previously mapped via APM_CMD_GLOBAL_SHARED_MEM_MAP_REGIONS.

Client is expected to send this unmap command only when the use case is ended. This is to ensure no module is actively using the global shared memory.
