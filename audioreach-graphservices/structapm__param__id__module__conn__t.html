Detailed Description

h2xmlp_parameter {"APM_PARAM_ID_MODULE_CONN", APM_PARAM_ID_MODULE_CONN} h2xmlp_description { ID of the parameter to configure the connection between module ports.


This parameter ID must be used under command APM_CMD_GRAPH_OPEN.
Configure connection links between each of the input and
output ports of modules present in the sub-graph.
Connection between source and destination module ports is
1:1 i.e. the source module's output cannot be routed to
multiple input ports of 1 or more destination modules.
Similarly, destination module's input port cannot accept
data from more than 1 output ports of one or more source
modules. Any such connection is treated as invalid
configuration and will be flagged as error to the client.
} h2xmlp_toolPolicy {RTC; Calibration}
