◆ ar_osal_mutex_create()

int32_t ar_osal_mutex_create ( ar_osal_mutex_t *  mutex)

Creates and initialize a mutex.

Recursive mutex are always used. Mutex memory allocation and initialization done by this API osal_mutex_create() or osal_mutex_init() would be used, but not both.

@datatypes ar_osal_mutex_t

Parameters
[Out]mutex: Pointer to the mutex object handle.
Returns
0 – Success Nonzero – Failure

@dependencies None. @newpage
