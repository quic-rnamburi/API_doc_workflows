Creates and launches a thread.

@datatypes ar_osal_thread_t

Parameters
[out]threadPointer to the thread.
[in]thread_attrPointer to the thread attributes.
[in]thread_startPointer to the entry function of the thread.
[in]thread_paramPointer to the arguments passed to the entry function. An argument can be to any pointer type. @detdesc The thread stack can be passed in as the osal_thread_stack argument, or osal_thread_stack=NULL indicates that osal allocates the stack internally. If the caller provides the stack, the caller is responsible for freeing the stack memory after joining the thread.
Pre-allocated stacks must be freed after the dying thread is joined. The caller must specify the heap in which the thread stack is to be allocated.
Returns
0 – Success Nonzero – Failure.

@dependencies None. @newpage
