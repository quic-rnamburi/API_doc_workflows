## Structures

### `apm_cmd_header_t`

Common payload header structure used by the following commands:

**Members**

<ParamField path="payload_address_lsw" type="uint32_t">
  Lower 32 bits of the payload address.
</ParamField>
<ParamField path="payload_address_msw" type="uint32_t">
  Upper 32 bits of the payload address.
</ParamField>
<ParamField path="mem_map_handle" type="uint32_t">
  Unique identifier for a shared memory address.
</ParamField>
<ParamField path="payload_size" type="uint32_t">
  Actual size of the variable payload accompanying the message or in shared memory.
</ParamField>

## Macros

### `APM_MODULE_INSTANCE_ID`

Identifier for an instance of the APM module.

```c
#define APM_MODULE_INSTANCE_ID 0x00000001
```

### `APM_CMD_GRAPH_OPEN`

Opens a list of one or more sub-graphs.

```c
#define APM_CMD_GRAPH_OPEN 0x01001000
```

### `APM_CMD_GRAPH_PREPARE`

Prepares one or more sub-graph IDs that were configured using APM_CMD_GRAPH_OPEN.

```c
#define APM_CMD_GRAPH_PREPARE 0x01001001
```

### `APM_CMD_GRAPH_START`

Starts one or more sub-graph IDs that were configured using APM_CMD_GRAPH_OPEN.

```c
#define APM_CMD_GRAPH_START 0x01001002
```

### `APM_CMD_GRAPH_STOP`

Stops one or more sub-graph IDs that were configured using APM_CMD_GRAPH_OPEN.

```c
#define APM_CMD_GRAPH_STOP 0x01001003
```

### `APM_CMD_GRAPH_CLOSE`

Closes one or more sub-graph IDs, data, and control links that were configured using APM_CMD_GRAPH_OPEN.

```c
#define APM_CMD_GRAPH_CLOSE 0x01001004
```

### `APM_CMD_CLOSE_ALL`

Used by the client to clean up all the allocated resources within the framework.

```c
#define APM_CMD_CLOSE_ALL 0x01001013
```

### `APM_CMD_GRAPH_FLUSH`

Flushes one or more sub-graph IDs that were configured.

```c
#define APM_CMD_GRAPH_FLUSH 0x01001005
```

### `APM_CMD_SET_CFG`

Configures one or more parameter IDs for one or more module instances that are present in the graph.

```c
#define APM_CMD_SET_CFG 0x01001006
```

### `APM_CMD_GET_CFG`

Used for querying one or more configuration/calibration parameter IDs that correspond to any module instance ID.

```c
#define APM_CMD_GET_CFG 0x01001007
```

### `APM_CMD_RSP_GET_CFG`

Returns a response code as an acknowledgment to APM_CMD_GET_CFG.

```c
#define APM_CMD_RSP_GET_CFG 0x02001000
```

### `APM_CMD_DB_DEFAULT_SET_CFG`

Payload for APM_CMD_RSP_GET_CFG.

```c
#define APM_CMD_DB_DEFAULT_SET_CFG 0x0100105E
```

### `APM_CMD_REGISTER_CFG`

Registers persistent calibration/configuration data that corresponds to one or more parameter IDs for one or more data/control processing modules.

```c
#define APM_CMD_REGISTER_CFG 0x01001008
```

### `APM_CMD_DEREGISTER_CFG`

De-registers persistent calibration/configuration data corresponding from one or more parameter IDs for one or more data/control processing modules.

```c
#define APM_CMD_DEREGISTER_CFG 0x01001009
```

### `APM_CMD_REGISTER_SHARED_CFG`

Registers shared persistent calibration/configuration data that corresponds to one parameter ID for a data/control processing module.

```c
#define APM_CMD_REGISTER_SHARED_CFG 0x0100100A
```

### `APM_CMD_DEREGISTER_SHARED_CFG`

Registers shared persistent calibration/configuration data that corresponds to one parameter ID for a data/control processing module.

```c
#define APM_CMD_DEREGISTER_SHARED_CFG 0x0100100B
```

### `APM_CMD_REGISTER_MODULE_EVENTS`

Registers or de-registers one or more event IDs for one or more module instances present in the graph.

```c
#define APM_CMD_REGISTER_MODULE_EVENTS 0x0100100E
```

### `APM_CMD_GET_SPF_STATE`

Queries for the SPF status.

```c
#define APM_CMD_GET_SPF_STATE 0x01001021
```

### `APM_SPF_STATE_NOT_READY`

Definition for the Not Ready state.

```c
#define APM_SPF_STATE_NOT_READY 0
```

### `APM_SPF_STATE_READY`

Definition for the Ready state.

```c
#define APM_SPF_STATE_READY 1
```

### `APM_CMD_RSP_GET_SPF_STATE`

Returns a response code as an acknowledgment for APM_CMD_GET_SPF_STATE.

```c
#define APM_CMD_RSP_GET_SPF_STATE 0x02001007
```

### `APM_EVENT_MODULE_TO_CLIENT`

Event raised by a module to the client if the event is registered by the client.

```c
#define APM_EVENT_MODULE_TO_CLIENT 0x03001000
```

### `APM_PARAM_ID_PATH_DELAY`

Parameter ID used to get the path delay from the APM.

```c
#define APM_PARAM_ID_PATH_DELAY 0x08001119
```

### `APM_CMD_GRAPH_SUSPEND`

Suspends one or more sub-graph IDs that were configured using APM_CMD_GRAPH_START.

```c
#define APM_CMD_GRAPH_SUSPEND 0x01001043
```

### `APM_PARAM_ID_SATELLITE_PD_INFO`

Used with APM_CMD_SET_CFG to set the satellite processor domain information to the master APM.

```c
#define APM_PARAM_ID_SATELLITE_PD_INFO 0x08001251
```
