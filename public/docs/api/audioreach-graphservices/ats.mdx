## Functions

### `ats_init`

ats_init Initializes the QACT Tuning Service.

```c
int32_t ats_init(void)
```

**Returns**

0 on success, non-zero on failure

### `ats_deinit`

ats_deinit Resets the QACT Tuning Service.

```c
int32_t ats_deinit(void)
```

**Returns**

0 on success, non-zero on failure
