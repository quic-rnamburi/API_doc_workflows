### `gsl_rtc_prepare_change_graph`

Prepare for graph change operation, this will update GSL state and close subgraphs and connections that are no longer needed but will not open anything on Spf.

This must be called before the ACDB data is updated.

```c
int32_t gsl_rtc_prepare_change_graph(struct gsl_rtc_prepare_change_graph_info *rtc_param)
```

**Parameters**

<ParamField path="rtc_param" type="struct gsl_rtc_prepare_change_graph_info *">
  pointer to struct gsl_rtc_prepare_change_graph, carries information about the RTGM operation to be performed
</ParamField>

**Returns**

AR_EOK on success, error code otherwise

### `gsl_rtc_change_graph`

Complete the graph change operation that is already prepared.

Note calling gsl_rtc_prepare_change_graph is mandatory before calling this API also the ACDB data on the device must be updated before calling this API.

```c
int32_t gsl_rtc_change_graph(struct gsl_rtc_change_graph_info *rtc_param)
```

**Returns**

AR_EOK on success, error code otherwise
