## Enumerations

### `processors`

Valid processor domain IDs.

#### Values

| Name | Value | Description |
|------|-------|-------------|
| `PROC_DOMAIN_ADSP` | = APM_PROC_DOMAIN_ID_ADSP | Audio DSP. |
| `PROC_DOMAIN_MDSP` | = APM_PROC_DOMAIN_ID_MDSP | Modem DSP. |
| `PROC_DOMAIN_SDSP` | = APM_PROC_DOMAIN_ID_SDSP | Sensors DSP. |
| `PROC_DOMAIN_CDSP` | = APM_PROC_DOMAIN_ID_CDSP | Hexagon Tensor Processor (previously called the compute DSP). |
| `PROC_DOMAIN_CC_DSP` | = APM_PROC_DOMAIN_ID_CC_DSP | Companion chip DSP. |

### `containerCapOld`

Valid container capabilities.

#### Values

| Name | Value | Description |
|------|-------|-------------|
| `APM_CONTAINER_CAP_INVALID_OLD` | = APM_PROP_ID_INVALID | Invalid capability ID. |
| `APM_CONTAINER_CAP_PP` | = APM_CONTAINER_CAP_ID_PP | Pre/postprocessing. |
| `APM_CONTAINER_CAP_CD` | = APM_CONTAINER_CAP_ID_CD | Compression or decompression. |
| `APM_CONTAINER_CAP_EP` | = APM_CONTAINER_CAP_ID_EP | Endpoint. |
| `APM_CONTAINER_CAP_OLC` | = APM_CONTAINER_CAP_ID_OLC | Offload container. |

### `containerCap`

Valid types of containers.

#### Values

| Name | Value | Description |
|------|-------|-------------|
| `APM_CONTAINER_TYPE_INVALID` | = APM_PROP_ID_INVALID | Invalid property ID. |
| `APM_CONTAINER_TYPE_SC` | = APM_CONTAINER_TYPE_ID_SC | Specialized container. |
| `APM_CONTAINER_TYPE_GC` | = APM_CONTAINER_TYPE_ID_GC | Generic container. |
| `APM_CONTAINER_TYPE_OLC` | = APM_CONTAINER_TYPE_ID_OLC | Offload container. |
| `APM_CONTAINER_TYPE_WC` | = APM_CONTAINER_TYPE_ID_WC | Wear container. |

## Macros

### `APM_CONTAINER_CAP_ID_PP`

Legacy capability identifier for pre/postprocessing.

```c
#define APM_CONTAINER_CAP_ID_PP 0x1
```

### `APM_CONTAINER_CAP_ID_CD`

Legacy capability identifier for compression/decompression.

```c
#define APM_CONTAINER_CAP_ID_CD 0x2
```

### `APM_CONTAINER_CAP_ID_EP`

Legacy capability identifier for an endpoint.

```c
#define APM_CONTAINER_CAP_ID_EP 0x3
```

### `APM_CONTAINER_CAP_ID_OLC`

Capability identifier for an offload container.

```c
#define APM_CONTAINER_CAP_ID_OLC 0x4
```

### `APM_CONTAINER_TYPE_ID_SC`

Container type identifier for a specialized container.

```c
#define APM_CONTAINER_TYPE_ID_SC 0x0B001000
```

### `APM_CONTAINER_TYPE_ID_GC`


### `APM_CONTAINER_TYPE_ID_OLC`

### `APM_CONTAINER_TYPE_ID_WC`

