### `acdb_ioctl`

Main entry function to the ACDB.

This entry function takes any supported ACDB IOCTL and provides the appropriate response.

See the individual command documentation for more details on the expectations of the command.

```c
int32_t acdb_ioctl(uint32_t cmd_id, const void *cmd_struct, uint32_t cmd_struct_size, void *rsp_struct, uint32_t rsp_struct_size)
```

**Parameters**

<ParamField path="cmd_id" type="uint32_t">
  Command ID to execute on the Audio Calibration Database. The cmd and the rsp must match the expected structures for that command. If not, the command fails.
</ParamField>
<ParamField path="cmd" type="">
  Pointer to the command structure.
</ParamField>
<ParamField path="cmd_size" type="">
  Size of the command structure.
</ParamField>
<ParamField path="rsp" type="">
  Pointer to the response structure.
</ParamField>
<ParamField path="rsp_size" type="">
  Size of the response structure.
</ParamField>

**Returns**

The result of the call as defined by the command.
