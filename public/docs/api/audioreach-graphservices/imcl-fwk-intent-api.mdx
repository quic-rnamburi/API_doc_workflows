## Macros

### `INTENT_ID_BT_DEADLINE_TIME`

Identifier for the IMCL intent used to send a deadline time.

```c
#define INTENT_ID_BT_DEADLINE_TIME 0x080010D3
```

### `INTENT_ID_AUDIO_DAM_DETECTION_ENGINE_CTRL`

Identifier for the IMCL intent used to define the payload structure of an IMCL message.

```c
#define INTENT_ID_AUDIO_DAM_DETECTION_ENGINE_CTRL 0x08001064
```

### `INTENT_ID_DETECTION_ENGINE_STAGE2_TO_STAGE1`

Identifier for the IMCL intent used for the control link between the detection engine and stage 2 detection engine.

```c
#define INTENT_ID_DETECTION_ENGINE_STAGE2_TO_STAGE1 0x0800124B
```

### `INTENT_ID_BT_ENCODER_FEEDBACK`

Identifier for the IMCL intent used to send sideband data to the encoder.

```c
#define INTENT_ID_BT_ENCODER_FEEDBACK 0x080010D7
```
