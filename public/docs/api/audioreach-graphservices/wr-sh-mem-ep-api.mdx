### `WR_SH_MEM_EP_EOS_POLICY_LAST`

EoS policy according to which last of the final end point raises the DATA_CMD_RSP_WR_SH_MEM_EP_EOS_RENDERED OR the last container which drops/renders the EoS raises the DATA_CMD_RSP_WR_SH_MEM_EP_EOS_RENDERED event.

```c
#define WR_SH_MEM_EP_EOS_POLICY_LAST 1
```

### `WR_SH_MEM_EP_EOS_POLICY_EACH`

EoS policy according to which each of the final EP raises the DATA_CMD_RSP_WR_SH_MEM_EP_EOS_RENDERED OR the each container which drop the EoS raises the DATA_CMD_RSP_WR_SH_MEM_EP_EOS_RENDERED event.

```c
#define WR_SH_MEM_EP_EOS_POLICY_EACH 2
```
