## Structures

### `audio_hw_clk_cfg_req_param_t`

Immediately following this structure is a variable length array of audio_hw_clk_cfg_t or clock ID structure.

**Members**

<ParamField path="num_clock_id" type="uint32_t">
  Number of clock ID's being configured.
</ParamField>

### `audio_hw_clk_cfg_t`

**Members**

<ParamField path="clock_id" type="uint32_t">
  Unique Clock ID of the clock being requested.
</ParamField>
<ParamField path="clock_freq" type="uint32_t">
  Clock frequency in Hz to set.
</ParamField>
<ParamField path="clock_attri" type="uint32_t">
  Divider for two clocks that are coupled, if necessary: divider = A/B, where A is the dividend and B is the divisor.
</ParamField>
<ParamField path="clock_root" type="uint32_t">
  Root clock source.
</ParamField>

### `audio_hw_clk_rel_cfg_t`

**Members**

<ParamField path="clock_id" type="uint32_t">
  Unique Clock ID of the clock being released.
</ParamField>

### `audio_hw_clk_rsp_cfg_t`

Immediately following this structure is a variable length array of audio_hw_clk_status_cfg_t structure.

**Members**

<ParamField path="num_failures" type="uint32_t">
  Number of failures while requesting for 1 or more clock ID's.
</ParamField>

### `audio_hw_clk_status_cfg_t`

**Members**

<ParamField path="clock_id" type="uint32_t">
  Unique Clock ID of the clock which failed to be requested/released.
</ParamField>
<ParamField path="status" type="uint32_t">
  Status representing why clock id request/release failed @ Non-Zero - Failure.
</ParamField>
