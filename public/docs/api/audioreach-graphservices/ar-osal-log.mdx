## Macros

### `AR_CRITICAL`

critical message, log unrecoverable condition .

```c
#define AR_CRITICAL (0x1)
```

### `AR_ERROR`

error message, represents code bugs that should be debugged and fixed.

```c
#define AR_ERROR (0x2)
```

### `AR_DEBUG`

debug message, required for debug.

```c
#define AR_DEBUG (0x4)
```

### `AR_INFO`

Use for vital info that needs to exist in default logs.

```c
#define AR_INFO (0x8)
```

### `AR_VERBOSE`

verbose message, useful primarily to help developers debug low-level code

```c
#define AR_VERBOSE (0x10
```

### `AR_LOG_VERBOSE`

#define AR_LOG_VERBOSE if (ar_log_lvl & AR_VERBOSE)
