## Structures

### `apm_cmd_header_t`

In-band : This structure is followed by an in-band payload of type, apm_module_param_data_t Out-of-band : Out of band payload can be extracted from the mem_map_handle, payload_address_lsw and payload_address_msw using the posal api posal_memorymap_get_virtual_addr_from_shmm_handle.

**Members**

<ParamField path="payload_address_lsw" type="uint32_t">
  Lower 32 bits of the payload address.
</ParamField>
<ParamField path="payload_address_msw" type="uint32_t">
  Upper 32 bits of the payload address.
</ParamField>
<ParamField path="mem_map_handle" type="uint32_t">
  Unique identifier for a shared memory address.
</ParamField>
<ParamField path="payload_size" type="uint32_t">
  Actual size of the variable payload accompanying the message or in shared memory.
</ParamField>

## Macros

### `APM_MODULE_INSTANCE_ID`

Instance ID of the Audio Processing Manager module.

```c
#define APM_MODULE_INSTANCE_ID 0x00000001
```

### `APM_CMD_GRAPH_OPEN`

```c
#define APM_CMD_GRAPH_OPEN 0x01001000
```

### `APM_CMD_GRAPH_PREPARE`

Prepares one or more sub-graph ID's that have been configured Graph prepare command is issued against APM module instance iD.

```c
#define APM_CMD_GRAPH_PREPARE 0x01001001
```

### `APM_CMD_GRAPH_START`

Starts one or more sub-graph ID's that have been configured using the APM_CMD_GRAPH_OPEN.

```c
#define APM_CMD_GRAPH_START 0x01001002
```

### `APM_CMD_GRAPH_STOP`

Stops one or more sub-graph ID's that have been configured using the APM_CMD_GRAPH_OPEN.

```c
#define APM_CMD_GRAPH_STOP 0x01001003
```

### `APM_CMD_GRAPH_CLOSE`

Closes one or more sub-graph ID's, data and control links that have been configured using the APM_CMD_GRAPH_OPEN command.

```c
#define APM_CMD_GRAPH_CLOSE 0x01001004
```

### `APM_CMD_CLOSE_ALL`

This command is used by the client for cleaning up all the allocated resources within the framework including.

```c
#define APM_CMD_CLOSE_ALL 0x01001013
```

### `APM_CMD_GRAPH_FLUSH`

Flushes one or more sub-graph ID's that have been configured Graph flush command is issued against APM module instance iD.

```c
#define APM_CMD_GRAPH_FLUSH 0x01001005
```

### `APM_CMD_SET_CFG`

Configures one or more parameter ID's for one more module instances present in the graph.

```c
#define APM_CMD_SET_CFG 0x01001006
```

### `APM_CMD_GET_CFG`

This parameter is used for querying one or more configuration/calibration parameter ID corresponding to any module instance ID.

```c
#define APM_CMD_GET_CFG 0x01001007
```

### `APM_CMD_RSP_GET_CFG`

The response code returned as an acknowledgment for the APM_CMD_GET_CFG command.

```c
#define APM_CMD_RSP_GET_CFG 0x02001000
```

### `APM_CMD_REGISTER_CFG`

This command is used for registering persistent calibration/configuration data corresponding to one or more parameter ID's for one ore more data/control processing modules.

```c
#define APM_CMD_REGISTER_CFG 0x01001008
```

### `APM_CMD_DEREGISTER_CFG`

This command is used for de-registering persistent calibration/configuration data corresponding to one or more parameter ID's for one or more data/control processing modules.

```c
#define APM_CMD_DEREGISTER_CFG 0x01001009
```

### `APM_CMD_REGISTER_SHARED_CFG`

This command is used for registering shared persistent calibration/configuration data corresponding to one 
 parameter ID's for any data/control processing modules.

```c
#define APM_CMD_REGISTER_SHARED_CFG 0x0100100A
```

### `APM_CMD_DEREGISTER_SHARED_CFG`

This command is used for registering shared persistent calibration/configuration data corresponding to one 
 parameter ID's for any data/control processing modules.

```c
#define APM_CMD_DEREGISTER_SHARED_CFG 0x0100100B
```

### `APM_CMD_REGISTER_MODULE_EVENTS`

Registers/de-registers one or more event ID's for one or more module instances present in the graph.

```c
#define APM_CMD_REGISTER_MODULE_EVENTS 0x0100100E
```

### `APM_CMD_GET_SPF_STATE`

```c
#define APM_CMD_GET_SPF_STATE 0x01001021
```
