## Structures

### `pause_ramp_params_t`

Payload for the PARAM_ID_SOFT_PAUSE_RAMP_PARAMETERS parameter.

**Members**

<ParamField path="period_ms_ramp_up" type="uint32_t">
  Duration of the up ramp.
</ParamField>
<ParamField path="step_us_ramp_up" type="uint32_t">
  Duration for which a constant gain is applied before calculating the next gain in the ramp up curve.
</ParamField>
<ParamField path="ramping_curve_ramp_up" type="uint32_t">
  Specifies ramp up of the ramping curve.
</ParamField>
<ParamField path="period_ms_ramp_down" type="uint32_t">
  Duration of the down ramp.
</ParamField>
<ParamField path="step_us_ramp_down" type="uint32_t">
  Duration for which the same gain is applied before calculating the next gain in the ramp down curve.
</ParamField>
<ParamField path="ramping_curve_ramp_down" type="uint32_t">
  Specifies the ramp down of the ramping curve.
</ParamField>
