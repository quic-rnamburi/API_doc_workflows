### `SPR_RENDER_MODE_IMMEDIATE`

Indicates that the render start time is immediate.

```c
#define SPR_RENDER_MODE_IMMEDIATE 1
```

### `SPR_RENDER_MODE_ABSOLUTE_TIME`

Indicates that the render start time is at given value of absolute time.

```c
#define SPR_RENDER_MODE_ABSOLUTE_TIME 2
```

### `SPR_RENDER_MODE_DELAYED`

Indicates that the render start time is at a specified offset from the current absolute time wall clock time.

```c
#define SPR_RENDER_MODE_DELAYED 3
```
