## Functions

### `MinkCom_getRootEnvObject`

Get a RootEnv object which can be used to initiate MINK-IPC based communication with QTEE.

```c
int MinkCom_getRootEnvObject(Object *obj)
```

**Parameters**

<ParamField path="obj" type="Object *">
  The RootEnv object requested by the client.
</ParamField>

**Returns**

Object_OK on success. Object_ERROR on failure.
