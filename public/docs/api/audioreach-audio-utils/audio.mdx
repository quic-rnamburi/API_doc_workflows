### `audio_has_proportional_frames`

For this format, is the number of PCM audio frames directly proportional to the number of data bytes?

In other words, is the format transported as PCM audio samples, but not necessarily scalable or mixable. This returns true for real PCM, but also for AUDIO_FORMAT_IEC61937, which is transported as 16 bit PCM audio, but where the encoded data cannot be mixed or scaled.

