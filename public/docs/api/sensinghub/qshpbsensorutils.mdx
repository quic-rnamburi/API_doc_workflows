## Functions

### `get_msg_id`

Extract the message ID from a client event stream.

Decodes only the msg_id field of the first sns_client_event_msg_sns_client_event in stream.

```cpp
uint32_t get_msg_id(pb_istream_t stream)
```

**Parameters**

<ParamField path="stream" type="pb_istream_t">
  A copy of the nanopb input stream positioned at the event.
</ParamField>

**Returns**

The decoded message ID, or 0 on failure.

### `decode_suids`

Nanopb repeated-field callback that decodes SUID lookup events.

Expects the stream to contain sns_client_event_msg_sns_client_event records carrying SNS_SUID_MSGID_SNS_SUID_EVENT payloads. Appends each discovered SUID to suid_list::suids and stores the datatype string in suid_list::datatype.

```cpp
bool decode_suids(pb_istream_t *stream, const pb_field_t *field, void **arg)
```

**Parameters**

<ParamField path="stream" type="pb_istream_t *">
  Nanopb input stream.
</ParamField>
<ParamField path="field" type="const pb_field_t *">
  Field descriptor (unused).
</ParamField>
<ParamField path="arg" type="void **">
  Pointer to a suid_list output context.
</ParamField>

**Returns**

true on success, false on decode error.
