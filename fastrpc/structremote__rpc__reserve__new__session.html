Detailed Description

Structure for remote_session_control, used with FASTRPC_RESERVE_SESSION request ID to reserve new fastrpc session of the user PD on the DSP.

Default sesion is always 0 and remains available for any module opened without Session ID. New session reservation starts with session ID 1.
