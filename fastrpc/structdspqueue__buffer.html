Detailed Description

Buffer reference in a packet.

The buffer must already be mapped to the DSP using the same file descriptor. The subsection of the buffer as specified by offset and size must fit entirely within the mapped buffer. Note that buffer references are tracked based on the buffer file descriptor, and taking/releasing a reference to a buffer applies to the entire buffer as mapped to the DSP, not just the subsection specified.
