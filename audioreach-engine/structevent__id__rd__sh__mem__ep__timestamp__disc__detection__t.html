uint32_t event_id_rd_sh_mem_ep_timestamp_disc_detection_t::flags

Frame flags.

@valuesbul{for bit 31}

  • 1 – Timestamp is valid
  • 0 – Timestamp is not valid

To set this bit, use RD_SH_MEM_EP_BIT_MASK_TIMESTAMP_DISC_DURATION_VALID_FLAG and RD_SH_MEM_EP_SHIFT_TIMESTAMP_DISC_DURATION_VALID_FLAG

All other bits are reserved; the SPF sets them to 0.
