Detailed Description

Payload for AMDB_PARAM_ID_MODULE_VERSION_INFO

The client is reponsible for filling out the proc_domain, num_modules, and module_id fields. Please note that since only one proc_domain is given it is the responsibility of the CLIENT to iterate through all of the PDs to look for the module of intrest.
