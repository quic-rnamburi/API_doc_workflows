Detailed Description

Payload for APM_PARAM_ID_MODULE_CTRL_LINK_CFG.

This structure contains configuration parameters.

Immediately following this structure is a variable length array of structure objects that correspond to each module control link property. The length of the array is determined by number of control link properties being configured.
