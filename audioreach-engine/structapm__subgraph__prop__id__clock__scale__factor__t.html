uint16_t apm_subgraph_prop_id_clock_scale_factor_t::duty_cycling_clock_scale_factor_q4

@h2xmle_range {0x0000..0xFFFF} @h2xmle_default {0x10} @h2xmle_description {Duty Cycling Clock Scale Factor, to be modified only if enable flag is set
i.e.

only for Duty Cycling Subgraphs.
clock scale factor of 2.5 means clock has to be bumped up by 2.5 times.
So, duty cycling is 1/2.5=0.4 or 40 percent.
100 ms data can thus be accumulated in 40 ms before going into island.
This value is 12-bit integer, 4-bit fraction.
Client sends as fixed point representation in param payload. This clock scale factor conditionally applied based on Non Real Time
propagated from subgraph downstream to this subgraph
and other properties based on usecase
Suppose same stream subgraph used for both LPI and non-LPI device.
So, enable_duty_cycling set for the subgraph always.
This clock scale factor to be used when device is LPI
Next clock scale factor to be used when device is non-LPI}
