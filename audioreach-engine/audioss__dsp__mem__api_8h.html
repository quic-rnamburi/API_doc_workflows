◆ AUDIOSS_DRAM_MEMORY

#define AUDIOSS_DRAM_MEMORY   1

The macro AUDIOSS_DRAM_MEMORY can be used to mention the type of memory that is to be allocated or freed. Currently only DRAM type is supported.

◆ PARAM_ID_RSC_AUDIOSS_DSP_MEM

#define PARAM_ID_RSC_AUDIOSS_DSP_MEM   0x0800151E

This param is used to allocate or free the DSP memory. The client can request for memory from the DSP and once the memory allocation is done client can read/write to that memory section. Client can free the memory using the same parameter. This can be considered as a remote malloc by client.
