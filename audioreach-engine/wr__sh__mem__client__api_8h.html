◆ MODULE_ID_WR_SHARED_MEM_CLIENT

#define MODULE_ID_WR_SHARED_MEM_CLIENT   0x0700105C

ID of the Write Shared Memory Client module.

This module has one static input port with ID 2 and output port with ID 1.

This module is supported only in Offload container. The modules functions as the Client to the MODULE_ID_WR_SHARED_MEM_EP module. The module send the data from the Master process domain to the Write End-point module in the satellite SPF.
