◆ PARAM_ID_ENCODER_OUTPUT_CONFIG

#define PARAM_ID_ENCODER_OUTPUT_CONFIG   0x08001009

Identifier for the parameter that configures the encoder.

Encoding occurs at the incoming sample rate, number of channels, and bit width. These parameters are controlled by the resamplers, MFC, channel mixer, or PCM converter. Not all encoders support the encoder output configuration.

◆ PARAM_VAL_UNSET

#define PARAM_VAL_UNSET   (-2)

Value of a configured parameter (like bits_per_sample and num_channels) is don't care .

The module should continue to use the previously set configuration (or module defaults).

For example, if the client is to control num_channels from the host but control bits_per_sample from the ACDB, the ACDB will have the value of -2. After a graph is opened, the host can issue a command with bits_per_sample = -2 and num_channels with a proper value.

◆ PCM_DEINTERLEAVED_PACKED

#define PCM_DEINTERLEAVED_PACKED   2

PCM data is de-interleaved packed.

A buffer of maximum size M with C channels and N/C actual bytes per channel is de-interleaved packed if (M - N) is zero.

◆ PCM_DEINTERLEAVED_UNPACKED

#define PCM_DEINTERLEAVED_UNPACKED   3

PCM data is de-interleaved unpacked.

A buffer of maximum size M with C channels and N/C actual bytes per channel is de-interleaved unpacked if (M - N) is nonzero.

Or, each channel has its own buffers where the actual length is less than the maximum length.
