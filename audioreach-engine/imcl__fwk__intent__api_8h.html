◆ INTENT_ID_AUDIO_DAM_DETECTION_ENGINE_CTRL

#define INTENT_ID_AUDIO_DAM_DETECTION_ENGINE_CTRL   0x08001064

Identifier for the IMCL intent used to define the payload structure of an IMCL message.

The SVA and Dam modules support the following functionalities:

  • Channel resizing – An input intent ID exposed by the Dam module. This intent allows resizing of the channel buffers based on the SVA module's buffering requirement.
  • Output port data flow control – An input intent ID exposed by the Dam module. This intent is used to open or close the Dam output port gates by SVA module.
  • Best channel output – This intent allows detection engines to send the best channel indices to the Dam module. Upon receiving the best channel indices, the Dam module outputs only the best channels from the given output port.
  • FTRT data availably information – An output intent ID exposed by the Dam module to send the unread data length [FTRT data] length present in channel buffers to the SVA module.
