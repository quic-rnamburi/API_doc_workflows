uint32_t num_sub_graphs
 

Detailed Description

Payload for APM_PARAM_ID_SUB_GRAPH_LIST.

Immediately following this structure is a variable length array of apm_sub_graph_id_t objects that correspond to each sub-graph configuration and properties. The length of the array is determined by the number of sub-graphs being configured.
