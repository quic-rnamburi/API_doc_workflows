uint32_t apm_cmd_global_shared_mem_unmap_regions_t::shmem_id

Unique identifier for the global shared memory.

This is the same ID which was sent in APM_CMD_GLOBAL_SHARED_MEM_MAP_REGIONS.

@values Any 32-bit value

The APM uses this handle to retrieve the associated shared memory regions and unmap them.
