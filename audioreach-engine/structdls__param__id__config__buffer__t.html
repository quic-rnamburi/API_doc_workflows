Detailed Description

Payload for #DLS_CMD_CONFIG_BUFFER.

Consists the 64-bit buffer starting address in buf_start_addr_lsw and buf_start_addr_msw. Followed by a single buffer size and the total allocated buffer size for DLS. Finally a configuration flag to config or deconfig the buffer information in the DLS
